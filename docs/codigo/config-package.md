# `package.json`

Arquivo-fonte: [package.json](../../package.json)

## Scripts

- `npm run dev`: inicia Next em desenvolvimento.
- `npm run build`: gera build de produção.
- `npm start`: inicia o build.
- `npm run lint`: executa ESLint.
- `npm test`: executa Vitest uma vez.
- `npm run test:watch`: mantém Vitest observando arquivos.

## Dependências relevantes

Next, React, Tailwind, Supabase, Leaflet e react-leaflet.
