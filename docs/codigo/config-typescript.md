# `tsconfig.json`

Arquivo-fonte: [tsconfig.json](../../tsconfig.json)

## Responsabilidade

Configura compilação estrita do TypeScript.

- `strict: true`.
- `noEmit: true`.
- Module resolution para bundler.
- Alias `@/*` aponta para a raiz do projeto.
- Inclui arquivos `.ts`, `.tsx` e `.mts`, inclusive tipos gerados pelo Next.
