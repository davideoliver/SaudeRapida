# `app/globals.css`

Arquivo-fonte: [app/globals.css](../../app/globals.css)

## Responsabilidade

Configura Tailwind, aparência global e estilos especiais que não cabem diretamente em classes utilitárias.

## Conteúdo

- Importa Tailwind CSS.
- Define fundo e texto padrão.
- Remove margem e impede rolagem da página, pois a tela usa altura total.
- Personaliza zoom e atribuição do Leaflet.
- Personaliza a barra de rolagem da lista.
- Implementa o fundo, trilha, progresso e ambulância da tela de carregamento.
- Define a animação da ambulância em 2,2 segundos.

A atribuição do OpenStreetMap é mantida visível para respeitar os créditos exigidos pelo mapa.
