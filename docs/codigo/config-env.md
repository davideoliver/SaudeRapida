# `.env.example`

Arquivo-fonte: [.env.example](../../.env.example)

## Variáveis

- `TOMTOM_API_KEY`: chave privada usada apenas pelo servidor.
- `SUPABASE_URL`: endereço do projeto.
- `SUPABASE_SERVICE_ROLE_KEY`: chave privada administrativa; nunca no navegador.
- `NEXT_PUBLIC_USE_MOCK`: ativa dados simulados no cliente.

O valor real fica em `.env.local`, que não deve ir ao Git.
