# saude_rapida
Um site similar ao Waze, onde usuários enviam o tempo de espera de uma unidade de saúde e o aplicativo informará aos demais usuários uma média de espera para cada relato obtido, havendo um mapa que mostra as unidades, distância, tempo de deslocamento com base no trânsito, e em conjunto o tempo de espera do atendimento da unidade.
